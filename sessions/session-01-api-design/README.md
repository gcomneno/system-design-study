# Sessione 01 – API Design

## Obiettivo

Studiare API Design trasformando materiale sorgente privato in contenuti didattici originali, tecnicamente revisionati e pubblicabili.

La SOT grezza della sessione vive localmente sotto `sources/private/session-01-api-design/` ed è deliberatamente esclusa da Git.

## Percorso didattico

La sessione non replica la suddivisione del materiale sorgente.

I concetti vengono riorganizzati in unità di apprendimento pensate per:

- comprensione progressiva;
- ragionamento sui trade-off;
- applicazione pratica;
- preparazione ai colloqui;
- autovalutazione successiva tramite quiz ed esercizi.

La mappa completa e lo stato di copertura sono disponibili in:

- [Study Map — English](study-map.md)
- [Mappa di studio — Italiano](study-map.it.md)

## Argomenti

Il percorso copre:

- API fundamentals;
- scelta dei protocolli;
- HTTP e HTTPS;
- WebSocket, AMQP e gRPC;
- TCP vs UDP;
- REST resource design;
- semantica HTTP ed error handling;
- filtering, sorting, pagination e versioning;
- GraphQL;
- authentication;
- authorization;
- API security.

## Regola di pubblicazione

Il repository pubblico contiene soltanto materiale originale e rielaborato.

Non vengono pubblicati:

- transcript completi;
- traduzioni integrali delle fonti;
- corpus derivati direttamente dai video;
- output grezzi GYTE;
- video o altri file binari sorgente.

La sorgente privata è materiale di lavoro, non materiale didattico canonico.

## Metodo

Per ogni unità:

1. individuare i concetti nella SOT privata;
2. eliminare rumore, ripetizioni e materiale promozionale;
3. verificare criticamente le affermazioni tecniche;
4. produrre una sintesi originale;
5. esplicitare trade-off, failure mode ed errori comuni;
6. preparare interview material ed esercizi;
7. preparare quiz e soluzioni per lo studio successivo.

## Stato

**Prepared.**

La fase di preparazione del materiale della Sessione 01 è conclusa.

Il prossimo passo, quando inizierà lo studio attivo, sarà usare le unità, l'interview bank, gli esercizi e i quiz come percorso di apprendimento e verifica. Nuovi materiali verranno aggiunti soltanto quando emergeranno esigenze reali durante lo studio.
